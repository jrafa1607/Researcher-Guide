# 📊🤖 Researcher Guide
This repository serves as a centralized collection of tools, platforms, and resources to support researchers in **Academic Writing, Literature Reviews, and Scientific Research**. It is designed to assist at every stage of the scientific method, from discovery to publication. This repository emphasizes practical discovery, literature management, and structural knowledge across various stages of the scientific research pipeline.

| Category | Description |
| :--- | :--- |
| **Writing & Editing** | Tools for drafting, formatting, and proofreading scientific papers. |
| **Reference Management** | Software to organize, cite, and manage academic references and bibliographies. |
| **Systematic Review** | Frameworks and tools dedicated to executing Systematic Literature Reviews (SLR). |
| **Periodicals & Databases** | Major indexing platforms and journals to search and download scientific literature. |
| **Research Events** | Notable international and national conferences, symposiums, and academic forums. |
| **Methodology Support** | Frameworks, guidelines, and standards for conducting rigorous scientific experiments. |

## 🛠️📝 Writing, Reference Management & Systematic Review Tools

Below is a curated list of high-quality tools to enhance academic writing, organize citations, and streamline Systematic Literature Reviews (SLR):

| Tool / Platform | Description |
| :--- | :--- |
| **[Mendeley](https://www.mendeley.com/)** | A free reference manager and academic social network that helps organize research, collaborate online, and generate bibliographies. |
| **[Zotero](https://www.zotero.org/)** | A free, easy-to-use open-source assistant to help you collect, organize, annotate, cite, and share your research sources. |
| **[Overleaf](https://www.overleaf.com/)** | An online, collaborative LaTeX editor that simplifies the process of writing, editing, and publishing scientific documents. |
| **[Rayyan](https://www.rayyan.ai/)** | A specialized web and mobile app designed to expedite the initial screening of abstracts and titles for systematic reviews. |
| **[Covidence](https://www.covidence.org/)** | A leading online software platform that streamlines primary screening, full-text review, data extraction, and quality assessment in SLRs. |
| **[Grammarly](https://www.grammarly.com/)** | An AI-powered writing assistant that assists with grammar checking, clarity, and tone adjustments for academic manuscripts. |
| **[Connected Papers](https://www.connectedpapers.com/)** | A visual tool to help researchers find and explore academic papers relevant to their field through interactive citation graphs. |

## 📚🏛️ Major Journal Databases & Periodicals

Use these prominent indexing systems and digital libraries to discover peer-reviewed articles, books, and conference proceedings:

| Database / Publisher | Description |
| :--- | :--- |
| **[ScienceDirect](https://www.sciencedirect.com/)** | Elsevier's leading platform of peer-reviewed scholarly literature, covering physical sciences, engineering, life sciences, and health. |
| **[IEEE Xplore](https://ieeexplore.ieee.org/)** | A powerful digital library providing access to technical literature in electrical engineering, computer science, and electronics. |
| **[Scopus](https://www.scopus.com/)** | One of the largest abstract and citation databases of peer-reviewed literature, scientific journals, books, and conference proceedings. |
| **[Web of Science](https://www.webofscience.com/)** | A publisher-independent global citation database used to track and analyze multidisciplinary scientific research impact. |
| **[Google Scholar](https://scholar.google.com/)** | A freely accessible web search engine that indexes the full text or metadata of scholarly literature across an array of publishing formats. |
| **[Periódicos CAPES](https://www.periodicos.capes.gov.br/)** | A virtual library consortium providing Brazilian academic institutions with access to high-impact international scientific content. |
